# studio-sasame

自作ブラウザゲームを公開するプラットフォームとなるWEBサイト。詳しくは [`docs/100_企画/110_コンセプト/111_コンセプト.md`](./docs/100_企画/110_コンセプト/111_コンセプト.md) を参照。

## 特徴

- **ビルドレス** — バンドラ(Vite/webpackなど)やnpm依存を使わず、ネイティブESモジュール(`<script type="module">` + `import`/`export`)だけで動く
- **工程別ドキュメント構成** — 企画・設計・開発・検証の4工程それぞれに成果物の置き場所を用意済み
- **AIエージェント運用込み** — 開発・検証をAIエージェントに委任する前提で、`.claude/agents/`とGitHub Issueテンプレートを用意済み

## はじめかた

1. ローカルで動作確認する場合は、`file://`ではなく簡易HTTPサーバー経由で`index.html`を開く(ESモジュールがCORSでブロックされるため)
   - 例: `npx serve .` や VS CodeのLive Server拡張など
2. 企画・設計の詳細は `docs/` 配下を参照

## ディレクトリ構成

```
studio-sasame/
├── index.html               エントリーポイント
├── assets/                  画像・フォントなどの静的アセット
├── docs/                    企画・設計・開発・検証の工程別ドキュメント
│   ├── 100_企画/
│   ├── 200_設計/
│   ├── 300_開発/
│   └── 400_検証/
├── .claude/agents/          開発・検証を担当するAIエージェント定義
└── .github/ISSUE_TEMPLATE/  タスク起票用のIssueテンプレート
```

各ドキュメントの規約・開発フローの詳細は [CLAUDE.md](./CLAUDE.md) を参照。
