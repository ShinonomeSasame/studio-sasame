# テスト仕様書

## Epic #1: 共通ヘッダーからどのページにも迷わず移動できる

- [ ] No.1 各ページ(HOME/ABOUT/GALLERY/CONTACT/プライバシーポリシー/PLAY)を開く → ヘッダーにロゴ「スタジオささめ」とハンバーガーボタンが表示される
- [ ] No.2 ロゴをクリックする → HOMEページへ遷移する
- [ ] No.3 ハンバーガーボタンをクリックする → ボタンの3本線が×の形に変わり、画面右端からメニューがスライドインし、HOME/ABOUT/GALLERY/CONTACT/プライバシーポリシーの5つのリンクが表示される
- [ ] No.4 メニューが開いた状態で、ハンバーガーボタン(×アイコン)をクリックする → メニューが右端へスライドアウトして閉じる
- [ ] No.5 メニュー内の各リンク(ABOUT等)をクリックする → 該当ページへ遷移する

## Epic #2: サイト全体で統一されたブランド/ビジュアルの基盤がある

- [ ] No.1 各ページを開き、背景色・見出しやリンクの色を確認する → 決定メモのカラーパレット(オフホワイト背景、藍色のキーカラーなど)通りの配色になっている
- [ ] No.2 各ページの見出し・本文を確認する → 「たぬき油性マジック体」(TanukiMagic)が読み込まれ、見出し・本文に適用されている
- [ ] No.3 各ページをブラウザで開き、タブに表示されるアイコンを確認する → favicon(`assets/images/favicon/favicon.png`)が表示される

## Epic #3: HOMEページで最新情報を確認できる

- [ ] No.1 HOMEページを開く → ページ上部に「お知らせ」欄が表示され、最新ゲーム欄より先(上)に配置されている
- [ ] No.2 「お知らせ」欄の内容を確認する → お知らせが日付付きで一覧表示される
- [ ] No.3 HOMEページを開く → 「最新ゲーム」欄にサムネイル・タイトル・説明文を含むカードが表示される
- [ ] No.4 最新ゲームカードをクリックする → 該当ゲームのPLAYページへ遷移する

## Epic #4: ABOUTページで作者・サイト情報を確認できる

- [ ] No.1 ABOUTページを開く → 作者プロフィール(アイコン・氏名・紹介文)が表示される
- [ ] No.2 ABOUTページを開く → サイト概要の文章が表示される
- [ ] No.3 SNSリンクをクリックする → Xアカウントのページが新しいタブで開く
- [ ] No.4 ABOUTページを開く → 共通ヘッダーが表示される
- [ ] No.5 ABOUTページでハンバーガーメニューを開閉する → Epic #1と同様にメニューが正しく開閉する

## Epic #5: GALLERYページで公開ゲームを探して見つけられる

- [ ] No.1 GALLERYページをデスクトップ幅で開く → ゲームカードが2列で表示される
- [ ] No.2 GALLERYページをモバイル幅で開く → ゲームカードが1列で表示される
- [ ] No.3 GALLERYページのカードを確認する → サムネイル・タイトル・説明文が1カード内に表示される
- [ ] No.4 複数のゲームが公開されている状態でGALLERYページを開く → 公開日が新しい順にカードが並んでいる
- [ ] No.5 GALLERYページのカードの見た目を確認する → 角丸・枠線・余白などのスタイルがカード間で統一されている
- [ ] No.6 GALLERYページのカードのサムネイルを確認する → 横長(1.91:1)のアスペクト比で表示される
- [ ] No.7 タイトルが長いゲームのカードを確認する → タイトル・説明文とも表示行数の上限が効いており、カードの高さが極端に伸びない
- [ ] No.8 GALLERYページを開く → 共通ヘッダーが表示される

## Epic #7: CONTACTページから問い合わせができる

- [ ] No.1 CONTACTページを開く → 氏名・メールアドレス・お問い合わせ内容の3つの入力欄が表示される
- [ ] No.2 いずれかの欄を未入力のまま「送信する」をクリックする → 送信されず、未入力の欄が分かるように表示される
- [ ] No.3 3項目すべて入力してから「送信する」をクリックする → 送信処理に進める(未入力エラーが出ない)
- [ ] No.4 全項目入力後「送信する」をクリックする → ボタンが押せない状態になり、「送信中です…」と表示される
- [ ] No.5 送信後、結果を確認する → 送信が成功した場合は完了メッセージ、失敗した場合はエラーメッセージが表示される
- [ ] No.6 CONTACTページでフォーム送信を行い、ブラウザのコンソールを確認する → JSの例外が発生しない
