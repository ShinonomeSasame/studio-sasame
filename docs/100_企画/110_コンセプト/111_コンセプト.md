# 概要
自作ブラウザゲームを公開するプラットフォームとなるWEBサイト
# ターゲットユーザー
- **作り手を追うファン**
	- SNSなどで東雲ささめという作り手の作風・感性に興味を持っている人
	- 個々のゲームの目新しさよりも、「この人が作るとこうなるか」という体験自体を楽しみたい層
	- 訪問のきっかけは新作の告知・更新であって、ジャンルや話題性そのものではない
- **SNS経由でたまたま出会う人**
	- 誰かがシェアした1本のゲームから流入してくる、作者のことはまだ知らない人
	- ルール説明を読む前提を持たず、数十秒で触って理解できることを期待する
	- 「シンプルなのに思ったよりハマった」という体験を通じて、拡張層からコア層へ転化することを狙う
# 目指すユーザー体験
- タイトルやサムネイルで独特な雰囲気を感じつつも、手軽にゲームを始められる
- ゲームにアップデートが行われていないかを確認するため再訪したくなる
