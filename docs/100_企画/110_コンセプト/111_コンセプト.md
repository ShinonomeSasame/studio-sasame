# 概要
自作ブラウザゲームを公開するプラットフォームとなるWEBサイト
# ターゲットユーザー
- タイパを重視し刺激を求めるが、AAAタイトルのような重厚長大なゲームには腰が重い社会人。シンプルな操作でも手の込んだ演出で快感を得られるゲームを求めている
- 特定ジャンルへの好みよりも「作者が作った」という点への関心・応援が一次的な動機で、広告に煩わされない落ち着いた環境で安心して遊べることを求めている
- 複数のゲームに共通する世界観・キャラクター・伏線のつながりに気づき、その全体像を知りたくなる
# 目指すユーザー体験
- サイトを訪れたら遊びたいゲームに迷わず辿り着ける(発見のしやすさ)
- 読み込みや操作でつまずくことなく、スムーズにプレイを開始できる
- 数分以内にそのゲームならではの面白さを実感でき、また次のゲームも試したくなる
