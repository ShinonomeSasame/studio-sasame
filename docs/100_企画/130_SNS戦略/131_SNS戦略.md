# 方針
「開発日記」を中心に据える。ただし無機質な進捗報告ではなく、試行錯誤や感情の動きを含めて発信し、人柄がにじむようにする。完全に無関係な日常投稿は行わない。
# プラットフォーム
Xに集中する。日本語圏のインディーゲーム開発者コミュニティが厚く、ハッシュタグ(#ゲーム制作など)を通じて発見されやすい。Instagramには当面手を広げない。
# 開始時期
アカウント自体は開設済みだが、投稿開始はゲームの構想・世界観・キャラクターデザインなどの中身がある程度固まってから行う(ゲームの完成そのものを待つ必要はない)。
# 投稿内容の出し分け
- 発信開始後すぐに見せてよいもの: 世界観の雰囲気、キャラクターデザイン、制作への想い
- ローンチ直前まで温存してよいもの: 独自性の高いゲームシステムの詳細な数値・バランス設計(演出上のサプライズを取っておくため)
# 懸念点の整理(著作権)
ゲームのアイデア・システム自体は著作権で保護されない(アイデア・表現二分論)。開発日記で構想を発信しても、投稿の有無で盗用リスクは変わらない。守られるのは具体的な表現(絵・文章・コードなど)で、これは公開の有無に関わらず創作時点で自動的に権利が発生する。
