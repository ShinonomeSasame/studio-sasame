# 主要機能と実装方針

サイトの主要機能ごとに、実装方針を書き溜めていく。見た目・ブランドに関する方針は `docs/200_設計/210_サイトデザイン/211_サイトデザイン.md` を参照。

## ゲームの組み込み方

- **各ゲームはiframeを使わず、HTML/CSS/JSファイルとして直接プレイページに組み込む（シンプル・ミニマムな構成を優先）**
	- ゲーム画面はPhaser製で、canvas要素として描画される
	- ゲームのマークアップは専用のラッパー要素で囲み、CSSクラス名/idの衝突を避ける
	- JSはESモジュール（`<script type="module">`）で読み込み、モジュールスコープによってサイト本体のスクリプトと自然に分離される
- **プレイページの構成**
	- 共通ヘッダー(ロゴ・ハンバーガーボタン) + ゲーム画面のcanvasのみ
- **canvasのレスポンシブ対応**
	- PhaserのScale Manager（`scale`設定）を利用する。基本はFITモード（アスペクト比を保ったまま親要素に収まるよう拡縮）を採用し、内部解像度の再計算やdevicePixelRatio対応はPhaser側に任せる
- **メタデータ管理**
	- GALLERYカード・プレイページのタイトル/サムネイル/説明文はHTMLに直書きする（公開本数が少ない想定のため、別データファイルは用意しない）
	- HOMEの「お知らせ」欄も同方針でHTMLに直書きする（広報の主軸はSNSであり、お知らせ欄はメンテナンス告知・新作公開告知程度の低頻度更新を想定）
- **favicon**
	- `assets/images/favicon/favicon.png` を使用する（実装時にサイズ・形式の調整が必要な場合あり）

## ハンバーガーメニューの動作

1. ヘッダー右端のハンバーガーボタンを押下する
2. ハンバーガーボタンが×ボタンに切り替わる
3. 画面右端から、各ページ(HOME/ABOUT/GALLERY/CONTACT/プライバシーポリシー)へのリンクを記載したメニューがスライドインする
4. リンクをタッチすると該当ページへ遷移する
5. ×ボタンをタッチするとメニューが元の位置(右端)へスライドアウトする

## OGP(SNSシェア時のカード表示)

- **対象範囲**: 全ページ(HOME/ABOUT/GALLERY/CONTACT/プライバシーポリシー/各PLAYページ)
- **画像(`og:image`)**
	- PLAYページ: GALLERYカードで使用しているサムネイル画像をそのまま流用する
	- HOME/ABOUT/GALLERY/CONTACT/プライバシーポリシー: ページタイトルのテキストのみを掲載した専用画像を別途用意する(5ページ共通のテンプレートデザインで作成)
	- 推奨サイズは1200×630px(1.91:1)。PLAYページ流用サムネイルのアスペクト比がこれと異なる場合の扱いは未確定(要確認)
- **説明文(`og:description`)**
	- PLAYページ: GALLERYカードに記載している説明文をそのまま流用する
	- HOME/ABOUT/GALLERY/CONTACT/プライバシーポリシー: 専用の簡単な文章を別途用意する
- **タイトル(`og:title`)**: 各ページのタイトルをそのまま使用する
- **Card種別**: Twitter Card は `summary_large_image` を採用する(画像を大きく見せるため)
- **実装方式**: メタデータ管理方針(HTML直書き)を踏襲し、各ページの`<head>`に`og:title`/`og:description`/`og:image`/`twitter:card`を直書きする
- **PLAYページ流用サムネイルとOGP推奨比率の統一**: GALLERYカードのサムネイル比率自体を1.91:1(1200×630px相当)に統一し、`og:image`にそのまま流用できるようにする(サムネイル作成が1回で両用途を兼ねる)
- **文言・画像の作成タイミング**: プライバシーポリシー本文、および専用画像内のテキスト・`og:description`の具体的な文言は、各ページの内容が固まる開発フェーズで実装と合わせて作成する(設計フェーズではブロックしない)
- **未決定事項(実装方針として先に決めておきたいもの)**
	- HOME/ABOUT/GALLERY/CONTACT/プライバシーポリシー用専用画像のビジュアル仕様(背景色・ロゴ配置など)。具体的な色コードの確定(プロトタイプ作成時)にあわせて決定する
